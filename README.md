# AWS Docker HTTPS Login Project

## Descrizione

Sistema web sicuro ospitato su AWS EC2 tramite Docker.

## Tecnologie

- AWS EC2
- Docker
- Apache
- PHP 8
- MySQL
- Bootstrap

## Avvio

docker compose up -d --build

## Credenziali Demo

prof1 / password123
prof2 / password123

## HTTPS

Il sito utilizza certificato SSL self-signed.

## Sicurezza

- Password hashate
- PDO prepared statements
- Sessioni sicure
- HTTPS obbligatorio
